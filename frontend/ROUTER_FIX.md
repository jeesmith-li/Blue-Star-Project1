# 前端优化说明

## 修复内容

### 1. 路由守卫优化
- ✅ 增加后端连接错误处理
- ✅ 后端未启动时自动退出登录
- ✅ 减少不必要的 API 请求

### 2. 组件优化
- ✅ MainLayout: 增加错误捕获
- ✅ Dashboard: 静默处理 API 失败
- ✅ 防止无限重试

### 3. 使用建议

**正确启动顺序**:
1. 先启动后端 (start-backend.bat)
2. 等待看到 "Started WebApplication"
3. 再启动前端 (npm run dev)

**如果后端未启动**:
- 前端仍可访问登录页
- 登录失败会提示后端未连接
- 不会无限请求 API

**推荐**:
使用 Mock 登录测试前端界面（后端未启动时）
